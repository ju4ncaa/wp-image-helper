# Image Helper para WordPress

Renombra, redimensiona y genera metadatos automáticamente para las imágenes que subes a WordPress usando la API de OpenAI.


## Funciones

- Renombrado automático de archivos según el contenido de la imagen  
- Redimensionado para optimizar peso y rendimiento  
- Generación automática de:
  - Texto ALT  
  - Título  
  - Descripción  
  - Etiquetas  
- Procesamiento automático al subir imágenes  

---

## Instalación

1. Descarga el plugin  
2. Sube la carpeta a `/wp-content/plugins/`  
3. Actívalo desde el panel de WordPress  


## Configuración

1. Ve a **Ajustes → Image AI Helper**  
2. Introduce tu API Key de OpenAI  
3. Guarda los cambios  


## Requisitos

- WordPress 5.8 o superior  
- PHP 7.4 o superior  
- cURL habilitado  
- Cuenta en OpenAI con acceso a la API  


## Notas

El plugin envía imágenes a OpenAI para analizarlas, lo que puede generar costos según tu uso de la API.
